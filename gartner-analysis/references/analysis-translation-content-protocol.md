# Gartner 分析内容翻译与保真协议

本文件只约束分析阶段的 Markdown/文本翻译内容、逐页锚点和翻译禁区。PDF 视觉分段、版式覆盖、字体嵌入和 PDF 重建流程统一读取 `gartner-pdf-zh-translation/references/pdf-translation-protocol.md`。

## 目录

1. 翻译目标
2. 预处理
3. 逐页翻译
4. 表格与图片
5. 术语规则
6. 质量检查

## 1 翻译目标

让读者可以从中文稿回到原 PDF 的具体页面核对内容。保真优先于语言润色；准确优先于版式美化。

每份翻译只处理一份 PDF。不要把两个年份、HC 与 MQ、原文与外部资料合并。

## 2 预处理

开始翻译前记录：

- 原文件绝对路径；
- 完整标题、Gartner ID、发布日期、作者；
- 报告类型和市场范围；
- PDF 总页数；
- 每页正文、表格、图片、脚注和页眉页脚状态；
- 无文本层、乱码、裁切或加密页面。

使用 PDF 文本抽取与页面渲染交叉检查。对图表页、双栏页和表格密集页必须查看渲染结果，不能只依赖线性文本。

建立任务内术语表，先引用共享术语真值表，再补充报告专属术语。至少覆盖：

- 技术与产品名；
- 厂商名；
- IEEE、IETF、3GPP、ETSI、NIST、CNCF 等组织和标准；
- HC 阶段、Benefit Rating、Years to Mainstream Adoption、Market Penetration 和 Maturity；
- MQ 象限与评价维度。

## 3 逐页翻译

每一原文页使用唯一、连续的 H2：

```markdown
## 原文第 12 页
```

在页码锚点内按原页面顺序恢复标题、段落、列表、表格、图片和脚注。跨页段落在开始页保留开头，在后续页继续，不为阅读顺畅而隐藏页边界。

开头只写翻译元信息：

```markdown
# 中文保真翻译：原报告英文标题

> 原报告：标题与 Gartner ID  
> 发布日期：YYYY-MM-DD  
> 原文页数：N  
> 翻译原则：技术、厂商、产品、标准和协议名称保留英文；描述性文字翻译为中文。  
> 核验状态：已核验 / 存在待人工核验页
```

不要写执行摘要、年度变化、外部背景或建议。

## 4 表格与图片

### 4.1 表格

- 保留表名、列名、行名、单位、脚注符号和合并关系含义。
- Markdown 无法表达复杂合并时，拆成可读表格并紧邻说明原合并关系。
- 不把空白单元格推断成“无”“不适用”或零。
- 对数值表逐单元格核对数字、单位、正负号、范围和百分号。

### 4.2 图片和图表

- 将原图导出到 `output_root/assets/{report-stem}/pNN-figure-N.ext`。
- 在对应页码下用绝对路径或交付目录可解析路径引用图片。
- 翻译图题、图注、图例和轴标签；技术名与厂商名保持英文。
- 不用 AI 重新绘制、补全或美化 Gartner 原图。
- 无法可靠导出时保留位置并写：`图 N：待人工核验，原因：……`。

### 4.3 脚注与法律文本

保留脚注编号、来源说明、方法限制、版权与免责声明。不要因为其不属于业务正文而删除。

## 5 术语规则

技术项标题必须保留英文原名；表格中的 `Technology (English)` 字段和固定元数据字段也必须保留源 PDF 的英文原名。技术、产品、厂商、组织、标准、协议、缩写、接口和版本号不得按字面硬译；共享术语表中的 `protected_technology_terms` 必须原样保留，`forbidden_technology_variants` 不得出现在译文中。首次出现时可采用“英文原名（中文解释）”或“中文解释（英文原名）”，后续统一使用英文原名。

| 类型 | 规则 |
|---|---|
| Technology/Product/Brand | 保留英文原名 |
| Vendor/Company | 保留英文原名 |
| 标准与协议 | 保留英文编号和名称 |
| 数字、百分比、年份、金额 | 原样保留，不改写为中文数字 |
| Gartner 方法术语 | 首次中英并列，后续使用统一中文 |
| 普通描述文字 | 忠实翻译，避免扩写和缩写 |

共享方法术语统一读取 [`analysis-terminology.md`](analysis-terminology.md)。其中 HC 阶段、Benefit Rating、采用年限、市场渗透率和 Maturity 的中文值不得在本文件另行定义。

MQ 评价维度 `Completeness of Vision`、`Ability to Execute` 首次中英并列，后续保持同一中文显示；不得在不同 Skill 中建立第二套译名。

## 6 质量检查

逐份运行覆盖脚本，并人工抽查首页、中间页、表格密集页和末页。

自动检查：

- 页码锚点从 1 到 PDF 页数连续且唯一；
- 原文数字和 Gartner ID 没有在译文中缺失；
- 用户指定的保护术语仍存在；
- 带编号的 Figure/Table 在译文中有对应图/表；
- 翻译稿不含 `<推理>`、`<估算>`、外部证据、趋势或战略章节。

若脚本因 PDF 文本层不足产生误报，记录具体页码并以渲染图人工核验；不要直接忽略失败。
