# 失败恢复

| 症状 | 处理 |
|---|---|
| marker 缺失、顺序错或块被合并 | 丢弃该批结果，按单块回退；不要手工猜测缺失句子。 |
| 缓存来自旧的视觉分块 | 移入 `assets/translation-cache/` 的旧版本目录，按当前 `layout_units` 重新生成。 |
| 中文溢出或字号异常小 | 先扩大同列空白和行框，再降低到不低于约 9pt；仍不适配则保留英文块并记录人工核验。 |
| 横向彩色矩阵文字消失 | 保留整个原矩阵或至少保留 mixed-color 单元；中文化标题、来源和页脚。 |
| 图表标签无法可靠编辑 | 保留原栅格/矢量图，审计稿注明图内标签按原样保留。 |
| 字体 tofu 或 PDF 不可复制 | 更换嵌入的 CJK TrueType 字体，重新构建并检查 `get_page_fonts()`。 |
| 页数、链接或图片数量变化 | 停止交付，回到源 PDF 重建；不要通过删页、扁平化或截图掩盖差异。 |
