# 翻译协议

## 预处理

记录源文件绝对路径、完整标题、Gartner ID、发布日期、作者、报告类型、物理页数、正文页脚范围、横竖版页范围和图片页。用文本抽取与渲染交叉检查双栏、图表、表格、脚注及异常页。

## 分段

- 同列、同样式、垂直间距不超过约 4pt 的视觉行合并为一个语义单元。
- 纯项目符号作为布局单元保留，不送模型翻译。
- 每一原文页在审计稿中使用唯一连续的 `## 原文第 N 页`；跨页段落保留页边界。

## 模型提示

批量请求使用页/块起止 marker。要求 marker 顺序不变、不得合并或遗漏块、数字和标点保持、保护 token 原样返回。缺 marker 时按块回退，不接受猜测性拼接。

## 版式

以源 PDF 作为矢量和图像底图，只遮盖可编辑文本块并嵌入 CJK 字体覆盖。扩展同列空白区域后再尝试缩放；正文最低约 9pt。不要重绘 Gartner 曲线、表格网格、彩色矩阵或栅格图。
